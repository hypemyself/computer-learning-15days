# 新生电脑课

一套面向完全零基础准大一新生的 15 天 Windows 11 与 Python 入门课程。

## 打开课程

直接双击 `用Edge打开课程.cmd`，脚本会检查并自动恢复本地课程服务器，再在 Microsoft Edge 中打开课程。服务器在后台运行，不需要保留命令行窗口。

如果希望使用本地网站地址，可以在此文件夹打开 PowerShell，运行：

```powershell
python -m http.server 8766
```

然后访问 `http://127.0.0.1:8766/?v=20261009-learning-v7`。

## 课程功能

- 15 天完整课程，每天约 60 分钟
- 概念讲解、分步跟练、独立任务和随机五题测验
- 每天至少有 10 道题的题库，每次随机抽取 5 道并支持换题
- 第 3、5、6、10、11、15 天有场景化练习和明确验收：ZIP 与备份恢复、资料及 AI 回答核验、隐私、作业提交核验、网课设备自检、结课综合交付
- 新练习追加在原有任务末尾；已有结课记录保留，新增任务可补做
- 三个安全的模拟实验：文件整理、网址判断和 PowerShell
- 每日学习笔记自动保存在本机，并随进度 JSON 一起导出
- 每个关键概念提供“换句话说、为什么重要、举个例子、怎么判断掌握”
- 选中页面上的文字后点击浮出的 `?`，可在理解助手中提问
- 错题自动进入复习中心，重新答对后自动标记完成
- 每天记录“需要复习 / 有提示能完成 / 可以独立完成”掌握度
- 可将学习进度导出为 JSON，并在另一浏览器中导入恢复
- 理解助手保留最近 30 条提问记录，支持继续追问
- 达标后推进下一天，进度自动保存在当前浏览器
- 桌面端与手机尺寸响应式布局
- 第 13–15 天附带可直接运行的 Python 示例
- 独立的 Codex 入门页面：28 天路线、界面标注图、提示词练习和结业测验

Python 示例位于 `exercises` 文件夹。课程进度只保存在本机浏览器中，不会上传。
